<ReleaseSection id="highlights" label="At a glance" title="What matters in beta.6">

- **Accordion now survives Tailwind Preflight.** The closing box no longer carries `hidden`, so Preflight's `[hidden] { display: none !important; }` cannot cancel the exit animation.
- **Chat links keep their affordance.** Attachment links declare an explicit underline instead of relying on the browser default that Preflight resets.
- **The reset audit is documented.** Every reference was checked with Tailwind 4.3.3 Preflight in the base layer; remaining differences are limited to invisible controls or icon-only surfaces.
- **The Tailwind recipe is supported.** The layered entry now documents Preflight explicitly, including the unlayered `styles.css` ordering rule.

</ReleaseSection>

<ReleaseSection id="packages" label="npm beta" title="Published packages">

<ReleaseSection id="compatibility" label="Tailwind and CSS" title="Preflight without surprises">

- Accordion removes `hidden` only while its closing box animates. Closed content still has `hidden`, `aria-hidden` and `inert`.
- `data-pimolu-motion="off"` and reduced motion close the decorative box immediately, without waiting for a hidden reset.
- Chat attachment links set `text-decoration: underline` explicitly; other anchors already declare their intended underline or quiet variant.
- Preflight belongs in the `base` layer before `pimolu`. If you import the unlayered `styles.css`, place it after Preflight.
- Avoid application rules that force `display` on `.pimolu-accordion__content`; use the component `animated` prop or the motion opt-out subtree instead.

</ReleaseSection>
