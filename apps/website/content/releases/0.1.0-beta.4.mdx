<ReleaseSection id="highlights" label="At a glance" title="What matters in beta.4">

- **Toast now covers the whole feedback lifecycle.** Loading and information tones, semantic or custom icons, promise helpers, in-place updates, dismissal callbacks, six positions and hover/focus timer pauses ship with responsive touch controls.
- **Button and Form share one loading contract.** Button adds `loadingIndicator`; FormSubmit inherits it and keeps submission disabled with `aria-busy`. FormSubmit and FormError gain their own reference pages, focused APIs and interactive examples.
- **Input keeps its themed surface during autofill.** Browser paint is clipped to the text, so translucent appearances, focus and forced colors stay consistent while editing.
- **Every changed reference explains its setup.** Authored Setup sections, generated previews and Updated badges make the install path and the live examples easier to follow.

</ReleaseSection>

<ReleaseSection id="components" label="React and CSS" title="Components and interactions">

- Toast accepts loading and info tones, semantic icons or a custom icon node, promise feedback and `toast.update`. Passing an existing id updates one card instead of duplicating it, and dismissal callbacks run once.
- Toast timers pause independently on pointer and keyboard focus. Six placements, translated dismissal labels, named icon classes and touch controls keep long stacks usable in short viewports.
- Button `loadingIndicator` replaces the decorative loader without changing the disabled or busy state. Omit it for the existing ring; pass null or false to hide the visual only.
- FormSubmit inherits Button loading props, and FormError exposes a stable root part. Both now have standalone references, setup modules and examples beside the Form guide.
- Input clips browser autofill paint to the text instead of covering the themed wrapper. Focus, high contrast and later editing preserve the same surface.
- Tabs and SegmentedControl keep the shared CSS sliding indicator, optional visible scrollbars and reduced-motion support.

</ReleaseSection>
