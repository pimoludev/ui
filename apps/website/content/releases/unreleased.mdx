<ReleaseSection id="library" label="Available in the workspace" title="The library">

- 129 React component families, from everyday controls to data surfaces, application layouts and media.

- Shared CSS with seven visual presets, light and dark modes, brand color, radius and density settings.

- Platform-neutral palette and visual-token data, with generated web assets and integrity checks.

- Opt-in layered CSS and typed named-part customization across all 129 component families, including compound descendants. Panel hooks follow portalled content; existing class props keep their targets.

- Input focus halo restored independently of preset shadows. Styled Select honors its control style; Dialog and Drawer panels accept local inline styles.

- Tabs adds a native CSS sliding indicator for every variant, including vertical and scrollable lists. Use `animated={false}` to disable animations, CSS variables to customize duration/easing, and `classNames.indicator` to style the surface. Reduced motion is respected.

- SegmentedControl shares the sliding indicator and adds optional horizontal/vertical scrolling. `showScrollbar` explicitly enables native bars on SegmentedControl and TabsList; bars stay hidden by default. Tabs galleries use wider responsive cards.

</ReleaseSection>

<ReleaseSection id="documentation" label="Website" title="A reference you can build from">

- An illustrated catalogue with search, categories and a direct path to each component's API.

- At least four real examples per family: interactive previews, readable copyable code and source-derived public types, with a standalone typed customization example for every reference.

- Integration and design-system guides, a palette explorer and original engineering articles in the journal.

</ReleaseSection>

<ReleaseSection id="refinements" label="Refined" title="Interaction refinements">

- Anchored menus apply logical alignment before viewport clamping; DropdownMenu focuses commands after its portal mounts.

- Scheduler exposes a grid keyboard model, including RTL navigation and focus return from a cell action.

- Kanban capacity limits no longer mark operable cards in full columns as disabled.

</ReleaseSection>

<ReleaseSection id="before-release" label="Still in progress" title="Before a public release">

- The library packages are published on npm at 0.1.0-beta.3.1. Install the beta with pnpm add @pimolu/react@beta @pimolu/web-styles@beta; a component-copy CLI is not announced.

- Deeper assistive-technology and visual review remains necessary for complex families and complete application workflows.

- React Native, Angular, direct CDN adapters and a Pimolu MCP server remain future directions.

</ReleaseSection>
