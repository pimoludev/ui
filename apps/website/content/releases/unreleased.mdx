<ReleaseSection id="workspace" label="Available in the workspace" title="The workspace">

- The workspace currently matches the **0.1.0-beta.8** preview: the restored slate/indigo Default, 141 free Blocks and the corrected floating panel placement. There are no unreleased source changes yet.

- 129 React component families, from everyday controls to data surfaces, application layouts and media, with seven visual presets, light and dark modes, brand colour, radius and density settings.

- Opt-in layered CSS and typed named-part customization across all 129 families, including compound descendants. Panel hooks follow portalled content; existing class props keep their targets.

- Stable anchored placement shared by Select, Combobox, MultiSelect, TreeSelect, Cascader, Mentions, DropdownMenu, Menubar, Popover, Tooltip, HoverCard, DatePicker and DateRangePicker, with focus loops that skip hidden, inert and disabled controls.

</ReleaseSection>

<ReleaseSection id="before-release" label="Still in progress" title="Before a stable release">

- The library packages are published on npm at 0.1.0-beta.8. Install the beta with pnpm add @pimolu/react@beta @pimolu/web-styles@beta; a component-copy CLI is not announced.

- The 5–8 person design review and the assistive-technology review remain necessary before 0.1.0 stable.

- Block previews use local sample state; they do not call real payments, email or authentication services.

- React Native, Angular, direct CDN adapters and a Pimolu MCP server remain future directions.

</ReleaseSection>
