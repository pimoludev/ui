- **141 free Blocks in the source website.** Each of the 46 available collections now has at least three authored variants. Commerce contains 54 compositions across product cards, details, galleries, lists, search, quick view, inventory, wishlists, carts, checkout, orders, order history, management, tracking, payment methods, promotions, reviews and live purchase notifications. Launch, Leaderboard and email verification also have dedicated collections. Every block provides its real source and a light/dark capture. Commerce transactions, authentication and notifications use explicitly local sample state; connect real services before production. These website additions do not introduce a new npm version.

- **Familiar colors, current design.** The source workspace restores the Default slate/indigo colors from commit [f01aca8](https://github.com/pimoludev/ui/commit/f01aca89fddeae45df523d90996ff492da3e0abb) in light and dark. The newer typography, radius, spacing, motion and layouts remain. Light secondary text changes from `#64748B` to `#607087` for contrast on muted surfaces; functional outlines and soft accent roles stay supported. Other presets keep their palettes. This restoration is not included in the published npm beta.7.

- **Ink & Signal ships in 0.1.0-beta.7.** Default uses warm paper/ink neutrals and an iris signal, with `control-border` separate from decorative `border`. The six other named palettes keep their existing colors; no eighth preset is introduced.

- **Optional typography and shape.** Default font roles name DM Sans, Newsreader for editorial displays, and IBM Plex Mono, each with fallbacks. The library downloads no fonts; the website self-hosts licensed fonts. Default control/surface radii are 10/16 px, and explicit radius and density choices retain precedence.

- **Real review surfaces.** Playground Design Lab provides marketing, validated local form and searchable dashboard compositions. A beta.6 reference can be shown alongside them. This work does not close the full visual or assistive-technology audit.

- 129 React component families, from everyday controls to data surfaces, application layouts and media.

- Shared CSS with seven visual presets, light and dark modes, brand color, radius and density settings.

- Platform-neutral palette and visual-token data, with generated web assets and integrity checks.

- Opt-in layered CSS and typed named-part customization across all 129 component families, including compound descendants. Panel hooks follow portalled content; existing class props keep their targets.

- Input focus halo restored independently of preset shadows. Styled Select honors its control style; Dialog and Drawer panels accept local inline styles.

- Tabs adds a native CSS sliding indicator for every variant, including vertical and scrollable lists. Use `animated={false}` to disable animations, CSS variables to customize duration/easing, and `classNames.indicator` to style the surface. Reduced motion is respected.

- SegmentedControl shares the sliding indicator and keeps a single scrollable track horizontally or vertically. `showScrollbar` changes only native bar visibility on SegmentedControl; bars stay hidden by default and overflow remains reachable. TabsList also supports `showScrollbar`. Tabs galleries use wider responsive cards.

- Toast adds loading and information states, semantic or custom icons, promise feedback and in-place updates. Timers pause during hover/focus, notifications support six positions, and dismissal labels, callbacks and named icon styling are customizable. New examples cover these additions, published in 0.1.0-beta.4.

- Button adds loadingIndicator for a custom decorative loader. FormSubmit inherits it while Form controls pending submission. Omitting it keeps the existing ring; null or false hides the visual without removing disabled or aria-busy. FormSubmit and FormError have their own reference pages and sidebar entries, with focused APIs, customization and interactive examples. This API addition ships in 0.1.0-beta.4.

### Nested tabs and focused authentication blocks

In the source workspace after beta.7, Tabs variants and orientations are scoped to their own lists and triggers. Nested line tabs no longer inherit segmented hover backgrounds from an outer Preview/Code switcher.

Password recovery and email verification blocks now use focused forms and inbox states, with less presentation copy. Resend, email correction and local validation remain interactive; these previews do not send emails or verify real identities. Block detail headings also give the free-block badge more space.

### Cleaner blocks and readable source

All 141 blocks now expose consistently formatted React source, with separate
variable declarations and readable event handlers. Previews remove repeated
category headings and default integration messages; feedback still appears after
actions. Onboarding screens show the actual setup fields directly.

Order history, inventory, order management, leaderboard and comparison tables
now use Pimolu table parts for consistent header and cell alignment. The empty
Testimonials subcategory has been removed from Marketing.

### Accessible block browsing

Selected category labels, card classifications and the setup link use readable
text colors across presets. The catalogue toolbar is a named region, with one
global skip link and a top-level main landmark. The sign-in block starts its
form heading at h2. Automated accessibility regressions cover the catalogue,
mobile category Drawer and sign-in preview in every preset and color mode.
