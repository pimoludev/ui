# @pimolu/web-styles

Plain CSS stylesheets for Pimolu UI components.

> **0.1.0-beta.1** — preview release.

```bash
pnpm add @pimolu/web-styles
```

Import the complete bundle once:

```ts
import "@pimolu/web-styles/styles.css";
```

Or import only the component CSS you use:

```ts
import "@pimolu/web-styles/button.css";
import "@pimolu/web-styles/input.css";
```

The full bundle includes Pimolu tokens, themes, presets, visual tokens and all
component styles. No Tailwind or CSS-in-JS runtime is required. Every component
stylesheet is also exported as a separate entry point.

Documentation: <https://github.com/pimoludev/ui>
