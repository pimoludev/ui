# @pimolu/web-styles

Feuilles de style CSS pour les composants Pimolu UI.

> **0.1.0-beta.1** — version de prévisualisation.

```bash
pnpm add @pimolu/web-styles
```

Importez le bundle complet une seule fois :

```ts
import "@pimolu/web-styles/styles.css";
```

Ou importez uniquement le CSS des composants utilisés :

```ts
import "@pimolu/web-styles/button.css";
import "@pimolu/web-styles/input.css";
```

Le bundle complet inclut les tokens Pimolu, les thèmes, les presets, les tokens
visuels et tous les styles de composants. Aucun runtime Tailwind ou CSS-in-JS
n'est nécessaire. Chaque feuille de composant est aussi exportée séparément.

Documentation : <https://github.com/pimoludev/ui>
