# @pimolu/design-tokens

Primitive design tokens for Pimolu UI, generated as CSS custom properties and JSON.

> **0.1.0-beta.1** — preview release. The public token names may still change.

```bash
pnpm add @pimolu/design-tokens
```

```ts
import "@pimolu/design-tokens/tokens.css";
```

```ts
import tokens from "@pimolu/design-tokens/tokens.json" with { type: "json" };
```

- `@pimolu/design-tokens/tokens.css` — `:root` primitives and light/dark semantic themes.
- `@pimolu/design-tokens/tokens.json` — the same data for build tools.

Documentation: <https://github.com/pimoludev/ui>
