# @pimolu/design-tokens

Tokens primitifs de Pimolu UI, générés en variables CSS et en JSON.

> **0.1.0-beta.1** — version de prévisualisation. Les noms publics des tokens peuvent encore évoluer.

```bash
pnpm add @pimolu/design-tokens
```

```ts
import "@pimolu/design-tokens/tokens.css";
```

```ts
import tokens from "@pimolu/design-tokens/tokens.json" with { type: "json" };
```

- `@pimolu/design-tokens/tokens.css` — primitives `:root` et thèmes sémantiques clair/sombre.
- `@pimolu/design-tokens/tokens.json` — les mêmes données pour les outils de build.
